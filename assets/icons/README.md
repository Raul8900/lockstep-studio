# Icons

Lucide 1.73.0 (ISC licence, see LICENSE): 2359 line icons on a 24-unit grid, stored as SVG path data.

In a scene: `icon(ctx, 'heart-pulse', cx, cy, size, COL.alert, { lw: 2, p: progress })`.
Find one: `bin/lockstep icons heart` searches the names; `names.txt` is the full list.
They are stroke icons: they take the style's colours and can draw themselves on.
