# Creative brief — Production choices laboratory

## Audience and promise

The audience is a video author evaluating reusable treatments before selecting one for a real story. This short laboratory shows the physical behavior of each treatment without claiming that arbitrary sample values describe the world. The promise is a reproducible visual and audio audition whose parameters can be changed directly.

## Angle

Five possible angles were considered: advertise the renderer, teach timing theory, compare visual methods, demonstrate asset loading, or measure throughput. The selected angle is comparison of visible methods, because an author needs to see motion and composition before choosing a recipe. Timing and throughput are documented in the accompanying engineering evidence rather than made into narration.

## Directions considered

### A — Sequential demonstration

Each treatment occupies the whole safe diagram area for a short interval. A label identifies the visual job and a deliberate arrival connects it to the preceding shot. This makes the fixtures easy to inspect at phone size and lets the author compare different media using one palette and clock. The risk is feeling like a menu; this is acceptable for a capability fixture.

### B — Simultaneous gallery

Six panels could display six treatments at once, encouraging direct comparison. However each panel would be too small for realistic labels, especially the equal-scale example and the anatomical schematic. It would also multiply the rendering load and obscure which optional backend creates the measured cost. This direction is rejected for the verification video.

### C — Narrated tutorial

A narrator could explain every input and helper while the examples run. That would teach the API well, but requires a longer production and repeats information better conveyed by the catalogue details. It would also hide the explicit music-only clock this fixture must exercise. The API is instead documented in a readable guide with executable examples.

## Chosen direction

Choose the sequential demonstration. Every shot receives an independent catalogue selection and its own editable inputs; the common palette holds the sequence together. Some shots change quantities, some reveal structure, and others simply establish depth. The laboratory tests actual transitions and exported pixels, not only static thumbnails, so the examples are useful starting points for authors.

## Hook

Three hooks were compared: a large typographic promise, a moving signal, or a skinned figure changing pose. The reel opens with the signal because direction and travel are legible immediately. The mixed fixture opens with layered growth to establish a calm pace before introducing biological change and a real three-dimensional pose. Neither opening needs a fabricated factual claim.

## Story shape

The reel is a sequence of six visual jobs: travelling signal, annotated evidence, number landing, equal-scale comparison, parallax depth, then a zoom connecting scales. Each shot lasts five music beats at one hundred twenty beats per minute, for fifteen seconds total. The mixed fixture uses three five-second chapters: layered growth, a schematic cell division, and a skinned three-dimensional clip. The explicit clock owns all chapter boundaries and accent markers. There is no speech or invented caption track.

## Pacing

The reel uses a steady pulse with visual accents on saved beat and frame markers. The mixed fixture gives each pose five seconds and uses a softer instrument kit. The samples stay short and restrained. Loops are deterministic and a reverse seek must reproduce the same frame on the same renderer.

## Visual world

These are editorial diagrams on a working studio surface. Routes, evidence panels and proportional bars share clear outlines and readable labels. Layered stems demonstrate depth through differing drift speeds; the cell is explicitly labelled schematic rather than an organism-specific illustration. The original hinge rig demonstrates deformation and a moving camera, while the mechanism fixture shows separated opaque layers so depth ordering and occlusion are visible. No outside footage or generated imagery is used.

## Style

The studio-grid style is used intentionally because this is an engine laboratory, adjacent to the original starter fixture. Its pale paper, dark ink and restrained blue, orange and violet roles make route endpoints and bar lengths easy to inspect. A dark cinematic alternative would emphasize lighting but conceal mistakes near black backgrounds; the light treatment makes those defects more obvious. This is a testing choice, not a default for narrative productions.

## Sound

The reel has an original local synthesized score at one hundred twenty beats per minute, plus a few explicit sample and synthesized accents. The mixed fixture uses the soft kit. Narration is intentionally absent. A gain rest exposes a reveal without demanding a sound for every visible motion. All sound choices are saved independently from shot selections.

## What would make this fail

A diagram that suggests a false quantity, an asset that loads after the first frame, or a clip that changes pose when sought backward would invalidate the fixture. So would captions containing words nobody spoke. A successful build must decode completely, retain the selected 3D pixels during transitions, contain real audio, and produce valid reports with speech metrics marked inapplicable.
